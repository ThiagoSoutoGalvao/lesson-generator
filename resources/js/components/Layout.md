# Layout — Main app header and navigation wrapper for authenticated pages

## Overview

This React component wraps the main content area of the app and provides a consistent header with navigation links and a logout button. Every authenticated page (upload, generate, library) is rendered inside this layout. The component is not specific to any single page — it's a shell that contains the page content via the `children` prop.

## File Location
`resources/js/components/Layout.jsx`

## Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| children | ReactNode | Yes | The page content to display below the header (e.g. the upload form, activity display, or library list) |

## What It Renders

```
┌─────────────────────────────────────────────────────┐
│ Lesson Generator                                    │
│                            Upload PDF | Generate | Library | Log out │
├─────────────────────────────────────────────────────┤
│                                                     │
│  {children}  — The main page content               │
│                                                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

The layout has a light gray background (`bg-gray-50`), a white header with a subtle border, and navigation links centered in the header. The main content area is constrained to a max width of 1280px and centered.

## Key Features

### Header Navigation

The header contains:

1. **Lesson Generator** (left) — A link to the home page (`/`). Clicking it returns the teacher to the main dashboard.

2. **Navigation Links** (right) — Three links that navigate to different pages:
   - **Upload PDF** → `/upload` — Page where the teacher uploads course books
   - **Generate** → `/generate` — Page where the teacher generates new activities
   - **Library** → `/library` — Page where the teacher views and manages saved activities

3. **Log out** (far right) — A form button that logs the teacher out

### Logout Form

The logout button is a form (not a link) because it must POST to `/logout` with a CSRF token for security. The implementation is:

```jsx
<form method="POST" action="/logout">
    <input type="hidden" name="_token" value={document.querySelector('meta[name="csrf-token"]')?.content} />
    <button type="submit" className="hover:text-gray-900">Log out</button>
</form>
```

**How it works:**
1. The browser renders an HTML `<form>` element with `method="POST"` and `action="/logout"`
2. When clicked, the form submits a POST request to the Laravel backend at `/logout`
3. The CSRF token is read from the `<meta name="csrf-token">` tag in `welcome.blade.php` and included in the form as a hidden input (`_token`)
4. Laravel's CSRF protection middleware verifies the token is valid
5. The `AuthenticatedSessionController::destroy()` method runs, clearing the session
6. The teacher is redirected to `/` and sees the login form (because they are no longer authenticated)

**Why the CSRF token is needed:** Laravel protects against Cross-Site Request Forgery (CSRF) attacks by requiring a token to be submitted with any form that modifies state (like logout). The token is generated by the server and must match the value in the session.

### Styling

- **Header:** White background with a subtle bottom border, padding on all sides, centered content
- **Navigation links:** Gray text that darkens on hover, gap of 1.5rem between items
- **Main content:** Light gray background, max width of 1280px (centered), with padding above and below
- **Styling system:** Tailwind CSS utility classes (e.g. `bg-white`, `border-b`, `px-6`)

## How It Fits Into the App

This layout is used on every authenticated page. Examples:

1. **Home page** (`/`):
   ```jsx
   import Layout from './Layout';
   
   export default function HomePage() {
     return (
       <Layout>
         <h1>Welcome, Teacher!</h1>
         <p>Choose an action:</p>
       </Layout>
     );
   }
   ```

2. **Upload page** (`/upload`):
   ```jsx
   <Layout>
     <UploadForm /> {/* PDF upload form */}
   </Layout>
   ```

3. **Generate page** (`/generate`):
   ```jsx
   <Layout>
     <GeneratePage /> {/* Activity generation form and activity display */}
   </Layout>
   ```

4. **Library page** (`/library`):
   ```jsx
   <Layout>
     <LibraryPage /> {/* List of saved activities */}
   </Layout>
   ```

The layout is consistent across all pages, so the teacher always sees the same header and navigation. Clicking the navigation links changes the current page (managed by React Router) without affecting the header.

### Authentication & Visibility

The Layout component itself does not check authentication — it assumes it is only rendered for authenticated teachers. If an unauthenticated teacher visits any page, Laravel's `auth` middleware (in `web.php`) redirects them to `/login` before the React app even loads. So by the time Layout is rendered, the teacher is guaranteed to be logged in.

The logout form works because the session is still active at the time the logout button is clicked. The `_token` input reads the CSRF token from the HTML `<meta>` tag, which was inserted by Laravel when the page was first loaded (in `welcome.blade.php`). This same CSRF token is also stored in the teacher's session, so when the form is submitted, Laravel can verify they match and allow the logout.
